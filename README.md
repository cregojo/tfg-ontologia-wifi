# tfg-ontologia-wifi
# Conectividad Inteligente

Diseño de una ontología semántica para la representación y análisis de puntos de acceso WiFi públicos utilizando tecnologías de la Web Semántica.

## Objetivo

Este proyecto forma parte del Trabajo Fin de Grado y tiene como objetivo modelar semánticamente la información de puntos WiFi públicos mediante una ontología OWL desarrollada en Protégé.

La ontología permite:

- Representar puntos WiFi públicos.
- Modelar proveedores, coberturas y ubicaciones.
- Realizar consultas SPARQL.
- Aplicar razonamiento semántico mediante OWL.
- Incorporar reglas SWRL para inferencia automática.

## Tecnologías utilizadas

- OWL 2
- RDF
- Turtle
- SPARQL
- Protégé
- HermiT Reasoner
- SWRL
- Python

## Estructura del repositorio

```text
data/       Datos originales
docs/       Documentación del proyecto
ontology/   Ontología OWL y recursos semánticos
scripts/    Scripts de transformación RDF
sparql/     Consultas SPARQL
```

## Inferencia semántica

La ontología incorpora:

- Clases inferidas mediante OWL.
- Reglas SWRL para clasificación automática según cobertura.
- Razonamiento mediante HermiT y Drools.
